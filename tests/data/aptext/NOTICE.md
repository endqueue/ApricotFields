# ApText's test data

- `aptext_test_a.ttf`, `aptext_test_b.ttf`: written by `aptext_tests
  --write-fonts`, from tables the test builds itself.
- `aptext_variable_abc.ttf`: Roboto's variable font cut to "a", "b" and
  "c" (weight and width axes), as HarfBuzz's tests ship it
  (`test/api/fonts/Roboto-Variable.abc.ttf`). Roboto is © Google, under
  the Apache License 2.0.
